PROTOCOL 03 / WELLNESS REQUEST

Innie Wellness Request Form

A handshake is available upon request.

Time Needed1–3 min

Use when

You cannot name the feeling, but you can identify what would help.

Ask yourself

“What does my Innie need to help my Outie make a decision?”

Select all requested supports

Your Innie may request multiple supports. Excessive specificity will not be penalized.
