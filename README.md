# The Testing Floor

A privacy-first, browser-only set of interactive grounding tools for high-stakes work.

## Included protocols

1. Decision Readiness Index (DRI)
2. Innie Systems Reporting Check
3. Innie Wellness Request Form
4. Testing Floor Communication Protocol
5. Innie Action Forecast

## Privacy design

- No login
- No database
- No analytics
- No form submissions
- No responses stored in localStorage or cookies
- All interaction happens only in the visitor's current browser tab

## Publish with GitHub Pages

1. Create a **public** GitHub repository, such as `testing-floor`.
2. Upload everything inside this folder to the repository root. `index.html` must be at the top level.
3. Open the repository's **Settings** tab.
4. In the left sidebar, choose **Pages**.
5. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder.
7. Click **Save**.
8. Wait a few minutes, then use the **Visit site** button shown in the Pages settings.

The address will usually look like:

`https://YOUR-USERNAME.github.io/testing-floor/`

## Update the site

Edit the files in GitHub or upload replacements. GitHub Pages republishes after each commit.

## Files

- `index.html` — site structure and written content
- `styles.css` — visual design and responsive layout
- `script.js` — all interactive behavior
- `assets/ci-globe.svg` — Continuous Improvement emblem
- `assets/favicon.svg` — browser tab icon

## Institutional use

This package uses a generic Continuous Improvement identity and fictional workplace scenarios. Before adding an organization's official name, logo, internal information, or employee data, follow the organization's branding, communications, IT, accessibility, records, and privacy requirements.

## Accessibility

The site includes semantic headings, keyboard-operable controls, focus indicators, labels, live result announcements, reduced-motion support, responsive layouts, and text labels in addition to status levels.
