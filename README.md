## Fonts

The CSS requests `Forma DJR` for titles and body copy and `Manifold Extended CF` / `Manifold CF` for buttons. Those commercial font files are **not included**. If a visitor does not have the fonts installed and no licensed webfont is configured, the site falls back to Helvetica Neue / Helvetica and Arial Narrow.

To use the exact fonts for every visitor, obtain webfont licenses and add the licensed files yourself using `@font-face`. Do not upload desktop-only font files without the appropriate web license.

## Publish with GitHub Pages

1. Create or open your public GitHub repository.
2. Upload **all files and the `assets` folder** from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then save.
6. Wait a few minutes and click **Visit site**.

The site stores no responses and requires no server or database.
